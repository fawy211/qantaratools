# QantaraTools Icon System v2 — Professional SaaS Style

The tool icons use a restrained, consistent visual language intended to feel like a professionally designed software product rather than a collection of AI-generated graphics.

## Design rules
- Local SVG assets; no icon CDN dependency for tool-card icons.
- Consistent rounded-square tile and line-glyph construction.
- Controlled gradients with close color values rather than loud multi-color effects.
- Subtle shadows and restrained hover motion.
- Tool name remains the primary accessible label.
- English-first presentation for the primary US/global audience.
- Light and dark themes remain supported without changing tool behavior.

## Product principle
The visual system should feel clear, useful, mature, and intentionally designed. It avoids excessive glow, decorative effects, and generic “AI” visual tropes.

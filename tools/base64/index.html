Frequently asked questions

What is Base64 used for?

Base64 represents binary data as plain ASCII text, so it can travel safely through systems that only handle text, such as JSON, HTML, email and URLs.

Is Base64 encryption?

No. Base64 is an encoding, not encryption. Anyone can decode it, so never use it to protect passwords or secrets.

Frequently asked questions

Does decoding a JWT verify it?

No. Decoding only reads the contents. Verifying a token requires checking its signature with the correct key on your server.

Is it safe to paste a JWT here?

The tool reads tokens without sending them anywhere. Even so, avoid sharing live production tokens with anyone and treat them like passwords.

Comment utiliser cet outil

Comparez deux versions d’un texte et repérez les contenus ajoutés ou supprimés directement dans votre navigateur.

  1. Collez ou saisissez votre texte.
  2. Choisissez l’opération ou la mise en forme.
  3. Copiez le texte traité.

Questions fréquentes

Puis-je comparer deux textes longs ?

Oui. Les textes très volumineux peuvent nécessiter davantage de temps selon les performances du navigateur.

Les différences sont-elles enregistrées ?

L’outil affiche la comparaison. Copiez ou enregistrez le résultat vous-même si nécessaire.

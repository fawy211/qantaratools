Comment utiliser cet outil

Faites pivoter et retournez des images horizontalement ou verticalement dans votre navigateur, puis enregistrez la version modifiée.

  1. Choisissez un fichier ou définissez vos options.
  2. Ajustez les paramètres disponibles.
  3. Vérifiez et téléchargez le résultat.

Questions fréquentes

Puis-je retourner une image horizontalement ?

Oui. Utilisez l’option de retournement horizontal si elle est proposée dans l’outil.

Le fichier original est-il conservé ?

Exportez l’image modifiée dans un nouveau fichier pour conserver l’original intact.

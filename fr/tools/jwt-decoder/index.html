Comment utiliser cet outil

Décodez les en-têtes et les charges utiles JWT dans votre navigateur sans envoyer les jetons à un serveur. Examinez la structure des JSON Web Tokens.

  1. Saisissez votre contenu dans l’outil ci-dessus.
  2. Choisissez les options souhaitées et lancez le traitement.
  3. Copiez le résultat dans votre projet.

Questions fréquentes

Le décodage vérifie-t-il la signature JWT ?

Non. Cet outil affiche le contenu décodé. La vérification de signature nécessite la clé appropriée et une procédure distincte.

Puis-je coller un jeton confidentiel ?

Évitez de partager des jetons actifs ou sensibles. Traitez les jetons Bearer comme des identifiants d’accès.

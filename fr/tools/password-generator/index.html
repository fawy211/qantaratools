Questions fréquentes

Comment créer un mot de passe robuste ?

Choisissez une longueur suffisante et plusieurs types de caractères adaptés. Utilisez un mot de passe différent pour chaque compte.

L’outil enregistre-t-il mon mot de passe ?

Le mot de passe est généré pour être affiché. Copiez-le dans un endroit sûr et ne le partagez pas.

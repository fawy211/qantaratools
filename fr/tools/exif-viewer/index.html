Comment utiliser cet outil

Examinez les métadonnées EXIF et les informations d’image, comme l’appareil photo et les détails de prise de vue, dans votre navigateur.

  1. Choisissez un fichier ou définissez vos options.
  2. Ajustez les paramètres disponibles.
  3. Vérifiez et téléchargez le résultat.

Questions fréquentes

Quelles informations les données EXIF peuvent-elles contenir ?

Selon l’image, elles peuvent inclure l’appareil, la date de prise de vue, les réglages et parfois la localisation.

Toutes les images contiennent-elles des données EXIF ?

Non. Les métadonnées peuvent être absentes ou avoir été supprimées auparavant.

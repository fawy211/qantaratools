Comment utiliser cet outil

Encodez les caractères spéciaux dans les URL ou décodez les séquences encodées en pourcentage. Traitez les composants d’URL directement dans votre navigateur.

  1. Saisissez votre contenu dans l’outil ci-dessus.
  2. Choisissez les options souhaitées et lancez le traitement.
  3. Copiez le résultat dans votre projet.

Questions fréquentes

Quand faut-il encoder une URL ?

Encodez les composants d’une URL lorsqu’ils contiennent des caractères réservés ou qui ne peuvent pas être utilisés directement.

L’encodage chiffre-t-il mon texte ?

Non. L’encodage d’URL modifie la représentation des caractères, mais ne chiffre pas les données.

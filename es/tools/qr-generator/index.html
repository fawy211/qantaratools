Preguntas frecuentes

¿Qué contenido puede incluir un código QR?

Un código QR puede contener, por ejemplo, una dirección web o un texto breve.

¿Un código QR funciona para siempre?

El código conserva el contenido introducido. Un enlace solo funcionará mientras el destino siga disponible.

Preguntas frecuentes

¿Qué formatos de archivo admite?

Admite CSV, TSV y JSON directamente. Los libros de Excel se pueden leer con la biblioteca de hojas de cálculo que carga la herramienta.

¿Puedo dividir los datos por el valor de una columna?

Sí. Elige una columna y se creará un archivo CSV por cada valor distinto. También puedes dividir por número de filas.

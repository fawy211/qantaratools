Preguntas frecuentes

Respuestas prácticas a preguntas habituales sobre QantaraTools, la gestión de archivos, la solución de problemas y el soporte.

Primeros pasos

¿Qué es QantaraTools?

QantaraTools es una colección de utilidades gratuitas en el navegador para trabajo, desarrollo, texto, imágenes, tareas con PDF, seguridad, finanzas y productividad diaria.

¿Tengo que instalar algo?

No. El sitio funciona directamente en un navegador moderno. Algunas herramientas pueden utilizar funciones del navegador o archivos cargados localmente.

¿QantaraTools es gratis?

Sí. El conjunto de herramientas web está pensado para ser gratuito. Algunas herramientas o funciones pueden tener límites o requisitos propios, descritos en su pantalla correspondiente.

¿Qué navegadores son compatibles?

Utiliza una versión reciente de Chrome, Edge, Firefox u otro navegador moderno. Mantenerlo actualizado mejora la compatibilidad.

Privacidad & Files

¿Se suben mis archivos a QantaraTools?

Muchas herramientas procesan los datos localmente en tu navegador. Si una herramienta depende de un servicio externo o de datos en tiempo real, su interfaz debe indicarlo. No subas información muy sensible si no conoces su método de procesamiento.

¿Dónde se guardan los archivos generados?

Los archivos generados normalmente se descargan mediante el navegador y se guardan según su configuración de descargas.

¿Por qué una herramienta solicita un archivo?

Las herramientas basadas en archivos necesitan acceder desde el navegador al archivo seleccionado para leerlo, transformarlo o generar un resultado. Seleccionarlo no significa por sí solo que se suba a un servidor.

¿Qué hago si falla un archivo grande?

Prueba con un archivo más pequeño, cierra pestañas innecesarias, actualiza la página e inténtalo de nuevo. Los límites de memoria pueden afectar a imágenes grandes, PDF o conversiones complejas.

Problemas habituales de las herramientas

No se abre un archivo Word, Excel o PDF generado. ¿Qué hago?

Download the file again, make sure the download completed, and open it with a current compatible application. If the issue continues, report the tool name, browser, operating system, and a brief description of the failure through Contacto Us.

Una herramienta PDF va lenta o parece bloqueada.

Los PDF grandes pueden necesitar bastante memoria y tiempo de procesamiento. Espera un momento y prueba con un documento más pequeño. Si falla repetidamente, informa del nombre de la herramienta y del tamaño aproximado.

Una herramienta de imagen ofrece un resultado deficiente.

Prueba con un formato habitual como PNG, JPEG o WebP y evita dimensiones demasiado grandes. Algunos metadatos o funciones avanzadas pueden no conservarse durante la conversión.

Una calculadora ofrece un resultado inesperado.

Comprueba las unidades, los datos introducidos, el tipo impositivo, la moneda y otras suposiciones. Las herramientas financieras y fiscales ofrecen cálculos informativos y no sustituyen el asesoramiento profesional.

Una herramienta para desarrolladores muestra un error.

Comprueba que la entrada sea válida para la herramienta seleccionada. Para JSON, SQL, expresiones regulares, JWT o datos codificados, verifica el formato y prueba con un ejemplo más pequeño.

Privacidad, Security & Accuracy

¿QantaraTools garantiza que todas las herramientas funcionan completamente sin conexión?

No blanket guarantee should be assumed. Many utilities are client-side, but some features can use external resources or live data. The Privacidad Policy and the individual tool behavior are the correct references.

¿Puedo utilizar QantaraTools con información confidencial?

Actúa con precaución. No introduzcas contraseñas, claves privadas, datos empresariales confidenciales ni otros materiales sensibles sin comprobar que el método de procesamiento de esa herramienta sea adecuado.

¿Se garantiza la exactitud de los resultados financieros?

No. Las herramientas financieras, de divisas, IVA, préstamos, descuentos y márgenes ofrecen cálculos informativos. Los tipos y las suposiciones pueden cambiar, por lo que debes verificar las cifras importantes por tu cuenta.

Informar de un problema

¿Qué información debo incluir al informar de un problema?

Incluye el nombre de la herramienta, lo que intentabas hacer, lo ocurrido, tu navegador y sistema operativo y, cuando corresponda, el tipo y tamaño aproximado del archivo. No envíes contraseñas ni contenido confidencial.

¿Cómo puedo contactar con QantaraTools?

Use the Contacto Us page. The Contacto Us page lists support@qantaratools.com. If you cannot reach us at that address, use the homepage tool-request option.

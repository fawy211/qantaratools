# QantaraTools — Tool Groups & Functional Guide

This document is the internal product reference for the current web toolkit. It describes what each group and tool is intended to do, typical use cases, and important limitations. It should be updated whenever a tool is added, removed, or its behavior changes.

## Platform-wide behavior

- QantaraTools is primarily a browser-based utility platform.
- Many utilities are designed for client-side processing, so data can often remain on the user’s device.
- A client-side design is not a blanket promise that every feature is offline or that no external resource is ever used.
- Users should verify important financial, tax, security, and business results independently.
- File size and browser memory can affect large images and PDFs.
- Tool output quality can depend on the input format and browser capabilities.

Häufig gestellte Fragen

Praktische Antworten auf häufige Fragen zur Nutzung von QantaraTools, zu Dateien, zur Fehlerbehebung und zum Support.

Erste Schritte

Was ist QantaraTools?

QantaraTools ist eine Sammlung kostenloser browserbasierter Werkzeuge für Arbeit, Entwicklung, Texte, Bilder, PDF-Aufgaben, Sicherheit, Finanzen und den Alltag.

Muss ich etwas installieren?

Nein. Die Website läuft direkt in einem modernen Browser. Einzelne Tools können Browserfunktionen oder lokal geladene Dateien verwenden.

Ist QantaraTools kostenlos?

Ja. Die Web-Werkzeugsammlung soll kostenlos nutzbar sein. Einzelne Tools oder Funktionen können eigene Einschränkungen oder Voraussetzungen haben, die auf der jeweiligen Tool-Seite beschrieben werden.

Welche Browser werden unterstützt?

Verwenden Sie eine aktuelle Version von Chrome, Edge, Firefox oder einem anderen modernen Browser. Ein aktueller Browser verbessert die Kompatibilität.

Datenschutz & Files

Werden meine Dateien zu QantaraTools hochgeladen?

Viele Tools verarbeiten Eingaben lokal in Ihrem Browser. Benötigt ein Tool einen externen Dienst oder Live-Daten, sollte die Oberfläche darauf hinweisen. Laden Sie keine besonders sensiblen Informationen hoch, wenn Sie die Verarbeitungsweise nicht kennen.

Wo werden erstellte Dateien gespeichert?

Erstellte Dateien werden normalerweise über Ihren Browser heruntergeladen und entsprechend dessen Download-Einstellungen gespeichert.

Warum benötigt ein Tool eine Datei?

Dateibasierte Tools benötigen Browserzugriff auf die ausgewählte Datei, um sie zu lesen, umzuwandeln oder eine Ausgabe zu erstellen. Die Auswahl bedeutet nicht automatisch, dass die Datei auf einen Server hochgeladen wird.

Was tun, wenn eine große Datei nicht verarbeitet wird?

Versuchen Sie eine kleinere Datei, schließen Sie nicht benötigte Tabs, laden Sie die Seite neu und versuchen Sie es erneut. Speichergrenzen des Browsers können große Bilder, PDFs oder komplexe Konvertierungen beeinträchtigen.

Häufige Tool-Probleme

Eine erstellte Word-, Excel- oder PDF-Datei lässt sich nicht öffnen. Was kann ich tun?

Download the file again, make sure the download completed, and open it with a current compatible application. If the issue continues, report the tool name, browser, operating system, and a brief description of the failure through Kontakt Us.

Ein PDF-Tool ist langsam oder scheint eingefroren zu sein.

Große PDFs benötigen möglicherweise viel Browser-Speicher und Verarbeitungszeit. Warten Sie kurz und versuchen Sie ein kleineres Dokument. Wenn der Fehler wiederholt auftritt, melden Sie den Namen des PDF-Tools und die ungefähre Dateigröße.

Ein Bild-Tool liefert ein schlechtes Ergebnis.

Verwenden Sie ein gängiges Format wie PNG, JPEG oder WebP und vermeiden Sie ungewöhnlich große Abmessungen. Einige Metadaten oder erweiterten Bildeigenschaften bleiben bei der Konvertierung möglicherweise nicht erhalten.

Ein Rechner liefert ein unerwartetes Ergebnis.

Prüfen Sie Einheiten, Eingaben, Steuersatz, Währung und andere Annahmen. Finanz- und Steuer-Tools dienen allgemeinen Informationszwecken und ersetzen keine professionelle Beratung.

Ein Entwickler-Tool zeigt einen Fehler an.

Prüfen Sie, ob die Eingabe für das ausgewählte Tool gültig ist. Kontrollieren Sie bei JSON, SQL, regulären Ausdrücken, JWTs oder codierten Daten das Format und versuchen Sie ein kleineres Beispiel.

Datenschutz, Security & Accuracy

Garantiert QantaraTools, dass alle Tools vollständig offline funktionieren?

No blanket guarantee should be assumed. Many utilities are client-side, but some features can use external resources or live data. The Datenschutz Policy and the individual tool behavior are the correct references.

Kann ich QantaraTools für vertrauliche Informationen verwenden?

Seien Sie vorsichtig. Geben Sie keine Passwörter, privaten Schlüssel, vertraulichen Geschäftsdaten oder sonstigen sensiblen Inhalte ein, bevor Sie geprüft haben, ob die Verarbeitungsweise des jeweiligen Tools dafür geeignet ist.

Ist die Genauigkeit finanzieller Ergebnisse garantiert?

Nein. Finanz-, Währungs-, Mehrwertsteuer-, Kredit-, Rabatt- und Aufschlagsrechner dienen allgemeinen Informationszwecken. Kurse und Annahmen können sich ändern; wichtige Werte sollten Sie selbst überprüfen.

Ein Problem melden

Welche Angaben sollte ich bei einer Fehlermeldung machen?

Nennen Sie das Tool, Ihr Vorhaben, das aufgetretene Verhalten, Browser und Betriebssystem sowie gegebenenfalls Dateityp und ungefähre Dateigröße. Senden Sie keine Passwörter oder vertraulichen Inhalte.

Wie kann ich QantaraTools kontaktieren?

Use the Kontakt Us page. The Kontakt Us page lists support@qantaratools.com. If you cannot reach us at that address, use the homepage tool-request option.

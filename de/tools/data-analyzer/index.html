Häufig gestellte Fragen

Welche Dateiformate werden unterstützt?

CSV, TSV und JSON werden direkt unterstützt. Excel-Dateien können mit der im Tool geladenen Tabellenbibliothek gelesen werden.

Kann ich Daten nach Spaltenwerten aufteilen?

Ja. Wählen Sie eine Spalte; für jeden eindeutigen Wert wird eine separate CSV-Datei erstellt. Alternativ können Sie nach Zeilenanzahl teilen.

Häufig gestellte Fragen

Was ist eine UUID v4?

Eine UUID v4 ist eine 128-Bit-Kennung, die aus zufälligen oder pseudozufälligen Werten erzeugt wird.

Sind UUIDs garantiert eindeutig?

Kollisionen sind äußerst unwahrscheinlich, aber kein Zufallsverfahren kann eine absolute mathematische Garantie geben.

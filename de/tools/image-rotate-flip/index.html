So verwenden Sie dieses Tool

Drehen und spiegeln Sie Bilder horizontal oder vertikal direkt im Browser und speichern Sie die angepasste Version.

  1. Wählen Sie eine Datei oder legen Sie Ihre Optionen fest.
  2. Passen Sie die verfügbaren Einstellungen an.
  3. Prüfen und laden Sie das Ergebnis herunter.

Häufig gestellte Fragen

Kann ich ein Bild horizontal spiegeln?

Ja. Verwenden Sie die horizontale Spiegeloption, sofern sie im Tool angeboten wird.

Bleibt die Originaldatei erhalten?

Exportieren Sie das bearbeitete Bild als neue Datei, damit das Original unverändert bleibt.

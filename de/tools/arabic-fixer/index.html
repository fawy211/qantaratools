Häufig gestellte Fragen

Wann sollte ich dieses Tool verwenden?

Verwenden Sie es, wenn arabischer Text in einer Anwendung oder einem Dokument falsch angeordnet oder dargestellt wird.

Übersetzt das Tool meinen Text?

Nein. Es dient der Textdarstellung und -korrektur, nicht der Übersetzung.

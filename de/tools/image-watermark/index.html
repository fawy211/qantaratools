So verwenden Sie dieses Tool

Fügen Sie Bildern Text- oder Bildwasserzeichen hinzu und exportieren Sie die markierte Version direkt im Browser.

  1. Wählen Sie eine Datei oder legen Sie Ihre Optionen fest.
  2. Passen Sie die verfügbaren Einstellungen an.
  3. Prüfen und laden Sie das Ergebnis herunter.

Häufig gestellte Fragen

Kann ich ein Textwasserzeichen verwenden?

Verwenden Sie die Textoption, sofern sie in den Wasserzeichen-Einstellungen verfügbar ist.

Wird das Originalbild verändert?

Speichern Sie das Ergebnis als neue Datei, damit Ihre Originaldatei erhalten bleibt.
